    \section{Introducción}
    %%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%

    Este documento presenta un sistema completo para el cálculo de propiedades psicrométricas utilizando correlaciones termodinámicas mejoradas. El sistema incluye:

    \begin{itemize}
        \item Ecuación virial con correlaciones de Tsonopoulos y Meng-Duan
        \item Método Lee-Kesler para condiciones extremas
        \item Reglas de mezcla mejoradas para sistemas aire-vapor
        \item Cálculo preciso de entalpía en exceso
    \end{itemize}
